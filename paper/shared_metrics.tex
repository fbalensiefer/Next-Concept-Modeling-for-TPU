For a teacher output law \(p_s\) and induced student law
\(p_{\theta,\psi}\), the reported output error is
\begin{equation}
 \mathrm{TV}(p_s,p_{\theta,\psi})=\tfrac12\sum_x|p_s(x)-p_{\theta,\psi}(x)|.
\end{equation}
Every codeword is enumerated and passed through the deterministic byte-argmax
decoder. An extra output bin retains probability outside the A/B domain.
Missing teacher support is \(\sum_{x:p_{\theta,\psi}(x)=0}p_s(x)\).
If this is positive, forward KL is infinite; JSON reports a null KL together
with the missing mass, not a smoothed finite substitute.

Hard conditional dependence is evaluated under the teacher-induced code law
\(P_{s,\psi}(i)=\sum_{x:Q_\psi(x)=i}p_s(x)\):
\begin{equation}
 \mathrm{TC}(I_k\mid I_{<k})=
 \sum_{j=1}^{n_k}\mathsf H(I_{k,j}\mid I_{<k})-
 \mathsf H(I_k\mid I_{<k}).
 \label{eq:tcmetric}
\end{equation}
Exact entropies are checked against an independent factorized-prior KL
calculation. The training surrogate instead enumerates a mixture of soft
assignment products; its gradients and numerical value do not certify the hard
code law. Enumeration is capped at 4096 codewords.

Byte reconstruction averages correct valid positions; sequence reconstruction
requires every valid byte to match. These are separate metrics. Coarse
perplexity is \(\exp\mathsf H(p_v^{\mathrm{hard}})\), using hard assignments;
the theoretical maximum is \(V\). Population values weight all domain inputs by
\(p_s\); monitored minibatch counts use actual global training assignments.
Teacher-forced code CE conditions on true earlier codes, whereas free-prefix
CE uses greedy earlier predictions. Their difference diagnoses exposure error;
neither is directly comparable to an AR next-byte perplexity, and paired
free-running byte accuracy is not a general quality score for unconditional
samples.
