# Experimental contract: hierarchy, information and generation cost

## Question and status

Can a learned hierarchy make text generation faster while preserving information and modeling the dependencies that matter?

The first target is fixed-length, unconditional UTF-8 byte generation on one public, document-identified text corpus. SCALE, pretrained-model conversion and operator transplantation are conditional extensions. Exact invertibility is a control, not a universal admission requirement.

This is a prospective protocol, not a report of completed experiments. The implementation reference is commit `f324da80890fc66d12a191944258941e02461d78`. Preserve that commit and its existing reports; run new experiments under separate identities. Reference results still need to be regenerated with an environment lock and recorded source/data hashes before being called reproducible reference results.

## Freeze before training

Record a machine-readable run manifest with the following fields before any new fit:

- Corpus name, public source, revision, license, download and processed-data hashes; document IDs and preprocessing rules.
- A modest fixed byte budget and document-level train/validation/test split. Deduplicate before splitting, preserve document boundaries, and never concatenate documents into a training window. Record excluded short documents and tail handling. Test documents remain sealed until model and operating-point selection ends.
- Lengths 32, 128 and 512 bytes; nonoverlapping full windows within documents for the primary evaluation. Specify UTF-8 boundary handling once; report validity of generated fixed-byte windows against the identically processed held-out reference.
- Exact architectures, level schedules, code capacities, optimizer schedules, checkpoint selection, training-byte exposure and accelerator-hour caps. Publish parameters and measured training cost rather than treating equal parameter counts as equal budgets.
- Model seeds 0, 1 and 2, one fixed split seed, and paired training orders where feasible. These estimate model-seed variation, not independent corpus replications. Record any additional split replications separately.
- Evaluation sample counts, sampling settings, checkpoint-selection rule, quality margins, fidelity tolerances and hardware configuration. No test-driven retuning.

Corpus choice, numeric budget caps, sample counts and application-dependent fidelity/quality margins remain open execution prerequisites. Fill them in and version the manifest before launching; this document alone is not a frozen numerical preregistration.

## Measurements and comparison rules

Reconstruction: report valid-byte accuracy, exact-window accuracy and errors by length, with document-level uncertainty intervals. Separately report punctuation, digit runs, names and repeated structures using a frozen extractor and a published stress suite. Stress-suite performance is diagnostic, not an estimate of corpus prevalence. Record invalid UTF-8, error positions and representative failures. Literal fallback metadata counts toward representation size and generation cost; no hidden input-byte side channel is allowed.

Generation: use the same held-out windows for all representations. Prespecify blinded human ratings of coherence and readability as the primary quality evaluation, including rubric, randomization, rater counts and aggregation before sampling. Report byte n-gram discrepancy, distinct windows, repetition, duplicate/training-window matches and UTF-8 validity alongside it. An external language model's score may supplement these checks, but cannot establish success alone. Report all prespecified sampling settings and their quality–latency frontier, including unsuccessful points.

Cost: measure complete prior sampling plus code reconstruction, decoder, resampling and output materialization; report device-only and host-visible boundaries explicitly. Report latency median/p90, throughput, batch size, generated bytes, sequential rounds and measured peak device memory. Compiler live-buffer estimates are separate from measured peak memory. Report compilation and warmup separately; synchronize before and after timing. Record codec, prior, autoregressive baseline and evaluation training costs separately, including failed fits and tuning trials.

Evidence: publish individual seed results, paired differences and 95% uncertainty intervals. Resample documents rather than treating correlated windows as independent; keep model-seed variability distinct from sampling/timing uncertainty. Repeated timings are not independent model replications. With three seeds, acknowledge weak precision. Do not compare latent-code cross-entropy directly with autoregressive byte likelihood; compare held-out prior loss only for the same frozen representation and normalization.

Success requires a reproducible improvement in the attainable quality–latency tradeoff after charging the complete generator and decoder, while satisfying the prespecified fidelity and quality margins. Use uncertainty intervals for the paired latency/quality differences; inconclusive intervals mean inconclusive evidence. Intermediate advantages may justify another bounded experiment, but must be named as such.

Run exact synthetic controls alongside the most tractable real-text candidates to explain mechanisms; do not let more synthetic tuning postpone real-text evidence. A scalable total-correlation estimator is not a prerequisite.

For a frozen code distribution P and a factorization with parent sets pa(i), the optimal factors are P(Z_i | Z_pa(i)). Then

`KL(P || q) = [sum_i H(Z_i | Z_pa(i)) - H(Z)] + sum_i E_P KL(P(Z_i | Z_pa(i)) || q_i(Z_i | Z_pa(i)))`.

The first term is omitted dependence; the second is conditional prediction error. The identity assumes normalized factors in a valid directed acyclic factorization (and suitable support). Hierarchical conditioning must be included in the parent sets. Bigger predictors address prediction error; representation or dependency changes address omitted dependence. On real text, controlled held-out prior loss and decoded output comparisons suffice to test whether extra dependencies help.

The [fixed-length duration/capacity follow-up](reconstruction-capacity.md) tests the initial fidelity failure with paired seeds, a single codebook-size intervention and exact raw/fixed-pair reconstruction controls. Its metrics remain exploratory; it does not satisfy the generation decision gate.

The [real-text dependency controls](text-dependency-priors.md) add stationary independent/first-order prior comparisons and decoded diagnostics. They do not establish quality or select a winning representation; a neural coarse-conditioned prior and cached AR comparison remain necessary.

## Changes after diagnosis

| Observed failure | Next intervention |
|---|---|
| Poor autoencoding fidelity, including with a strong prior | Improve codec capacity or training; a prior cannot restore information lost by the codec. |
| Good reconstruction; independent prior weak, structured prior strong | Change sampling factorization before redesigning quantization. |
| Good small-domain results; weak held-out text results | Investigate generalization, data scale and representation bias. |

Test representation changes individually: reconstruction-first training followed by limited dependency optimization; validation-based checkpoint acceptance; a narrowly scoped reversible control; or revised levels/block sizes. A weighted loss is not a fidelity guarantee, and sampled acceptance is not a population guarantee. Accept changes only if generation benefits survive independent fidelity evaluation. Stable utilization alone is insufficient. Simplify if fixed blocks perform similarly.

## Conditional extensions

After a useful scratch-trained generator exists, compare scratch training, teacher-generated data or predictive distillation, and matched-conditioning feature alignment. Keep shifted feature targets as diagnostic controls and address their missing information. Charge teacher inference, feature extraction and all adaptation costs. Pursue SCALE only after simpler transfer shows reproducible value. Feature similarity alone does not establish operator transplantation or cross-size compilation. Koopman methods are outside the critical path.

## Existing evidence and implementation gaps

- [Frozen-codec dependency comparison](../reports/dependency-validation/report.md): 480 finite-domain fits support testing sparse dependencies; they do not establish text quality or accelerator speed.
- [CPU benchmark](../reports/milestone3-benchmark/report.md): cached AR and actual-length inference already exist; long-shape timings use untrained models and do not establish matched quality.
- [Invertible controls](invertible-baselines.md): useful analytic controls, not a requirement that learned text codecs be exactly reversible.
- [Alignment diagnosis](../reports/alignment-diagnosis/report.md): motivates matched-conditioning transfer experiments later.
