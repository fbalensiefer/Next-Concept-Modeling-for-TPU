# Recorded CPU experiments

These compact reports preserve the observed positive and negative results from
the implementation work. Trained checkpoints, optimizer snapshots, generated
source archives and profiler traces remain in the ignored `runs/` directories.
They are regenerated by the documented experiment commands.

| Study | Recorded result |
|---|---|
| [Real-text dependency controls](text-dependency-priors/report.md) | Ten stationary prior fits; local dependencies help, with no learned-code generation advantage demonstrated |
| [Fixed-length duration/capacity follow-up](reconstruction-capacity/report.md) | Six paired CPU fits distinguish longer training and larger codebooks; exact controls remain lossless |
| [Real-text reconstruction pilot](real-text-reconstruction/report.md) | Nine short CPU fits on book-separated text; substantial byte errors and almost no exact reconstruction |
| [CPU benchmark](milestone3-benchmark/report.md) | Cached AR baseline and padded versus actual-length NCM inference; longer shapes are untrained |
| [Initial SCALE pilot](milestone4-scale-verified/report.md) | Three-seed mechanism gates passed; one run lost rare teacher support |
| [Four-arm decoder replay](scale-coverage-followup/report.md) | Stronger coverage and reliable-alignment gates failed on new seeds |
| [Balanced-codec follow-up](scale-balanced-coverage/findings.md) | Coverage passed; reliable teacher-alignment benefit remained unproven |
| [Coarse-codebook stability](coarse-codebook-stability/report.md) | All 20 new-seed models passed hard-usage and coverage checks; teacher-transfer superiority remained unproven |
| [Matched maintenance ablation](maintenance-ablation/report.md) | Unguarded EMA collapsed; recovery and fixed binary coarse endpoints retained stability in paired exploratory runs |
| [Fresh-seed domain validation](fresh-domain-validation/report.md) | 360 runs across six binary distributions; no quantizer passed all fidelity checks, and factorization remained limiting |
| [Reconstruction-first dependency comparison](dependency-validation/report.md) | 480 training-only prior fits on frozen reference codecs; joint and sparse conditional models improved output laws |

Each JSON report records its configuration, seed sets, software versions,
implementation hashes and limitations. Source evolved between studies, so older
frozen observations are not guaranteed bit-for-bit reproducible from current
`main`. The final coarse-codebook report's implementation hashes match the
published package sources. Its [validation record](coarse-codebook-stability/validation.json)
reports 44 passing tests, exact resume checks and virtual four-device CPU checks.
These CPU and finite-domain results do not establish TPU performance or useful
large-language-model transfer.

Run the current maintained experiment from the repository root:

```bash
python -m ncm.scale_experiment --config examples/scale/coarse_stability.json --output runs/coarse-stability
```

The experiment saves its exact package source snapshot and protocol before
training. See the repository README and `docs/coarse-codebooks.md` for other
experiments and configuration details.

## Replay without trained checkpoints

- `python examples/replay_dependency_results.py` verifies all 480 fits from compressed committed codec tables.
- `python examples/alignment_diagnosis.py` replays the feature-target diagnosis from committed activations.
- `python examples/domain_source_baselines.py` verifies analytic schedule and invertible-innovation controls.
- `python examples/summarize_maintenance.py` and `python examples/summarize_domain_validation.py --from-reports` regenerate summaries from archived observations.

The maintenance runner now includes its small historical teacher-domain input. The broader-domain runner generates its own sources and feature teachers. Training checkpoints remain ignored; the public replay inputs record their identities without requiring those checkpoints. Historical protocols and source hashes identify the actual executed versions, which can differ from later replay/diagnostic improvements. These counts are model fits, not independent dataset replications.

Additional mathematical controls: [invertible innovations](invertible-baselines/report.md). Additional diagnostics: [causal alignment target](alignment-diagnosis/report.md).
